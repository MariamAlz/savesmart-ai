# SaveSmart AI

> **Project:** Senior Design Project (team) · BSc Computer Engineering, Khalifa University · 2nd place in energy efficiency, Solar Decathlon Middle East

LSTM models (Keras) that forecast solar output and power use and recommend when to run appliances, for the SaveSmart app.

Part of the SaveSmart senior design project. See also the [Xamarin app prototype](https://github.com/MariamAlz/SaveSmart).
